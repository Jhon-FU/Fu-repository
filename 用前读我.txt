单词机 · 社区版
用前读我

这是一个帮你每天记单词、按计划复习的小工具。
不用注册软件账号，学习记录保存在自己的电脑上。
普通学习可以断网使用；AI 联想是可选功能，不配置也能正常学习。

一、第一次用，先做这几步

1. 把整个软件文件夹解压到一个固定位置，不要直接在压缩包里运行。
2. 双击 WordMachineCommunity.exe 打开软件。
3. 第一次会出现词库选择窗口。选一个推荐词库，点击“使用所选词库”；也可以导入自己的词库。
4. 在首页或“菜单 → 学习计划”里设置每日数量、考试日期或新词学完日期。
5. 点击“开始学习”，按提示完成今天的新词和复习。

这个运行包适用于 64 位 Windows，已经带上运行所需的组件。
如果你下载的是源码文件夹，需要先构建程序；开发方法见 README.md。

二、每天怎么学？

先判断自己认不认识这个词，再查看释义、联想等内容。
检测时回忆中文意思，查看答案后，按自己的真实掌握程度评分。
当前版本不要求输入英文拼写，也没有单独的拼写检测开关。

看见已经掌握、不想再学的词，可以跳过；需要恢复时去“菜单 → 已跳过词”。
今天的任务完成后，点击“结束今日学习”退出。
已经开始当天任务后再修改每日数量，会从明天起生效。

请先了解：当天任务完成前，软件会阻止普通关闭操作。
这是本软件督促每日学习的功能。遇到紧急情况，可用任务管理器结束程序；系统关机不受阻止。

三、错题小卡片怎么暂时隐藏？

答错或只想起一点的单词，会出现在“今日易错词”小卡片上。
可以拖动卡片的标题栏调整位置，碰到屏幕可用区域的边缘就会停住，不会被拖到屏幕外。

需要暂时收起时，点击卡片上的“答题隐藏 1 小时”。
软件会从卡片当前显示的错题中随机抽一个，请你先输入中文意思，再查看答案并自评：
基本说对：卡片隐藏 1 小时，时间到后自动重新出现。
只想起一点、完全忘了或想不起来：卡片继续显示，等 2 分钟才能再答一次。
中途取消或直接关闭答题窗口，也需要等 2 分钟，不能靠反复关闭来重新抽题。

等待期间按钮会暂时禁用，卡片显示剩余时间；时间到后再点击即可。
答题过程中，卡片上的释义会暂时遮住，避免直接看答案；卡片窗口本身不会被收起。
这次抽查只决定卡片是否休息，不修改正式学习成绩、答案或复习计划。
隐藏和等待的截止时间会保存在本机，重新打开软件后仍按剩余时间继续。
自动重新出现的前提是软件仍在运行，且当前词库还有需要显示的错题。

四、想让它每天开机提醒你？

先把软件放在准备长期使用的位置，再点击：
菜单 → 一键开启开机自启动

之后每次登录当前 Windows 账号，系统会自动打开它。
第一次运行不会替你开启自启动，只有你主动点击后才会添加。

需要撤销时，双击程序旁边的“撤销开机自启动.cmd”。
撤销入口放在文件夹里，软件菜单中没有关闭自启动的按钮。
这个脚本只撤销社区版的启动项，不删除学习记录，也不会关闭当前窗口。

如果移动了软件文件夹，请在新位置打开程序，再从菜单更新自启动路径。
如果 Windows 禁用了它的启动权限，还需要在系统的启动应用设置里允许它运行。

五、词库怎么选、怎么导入？

“菜单 → 词库管理”里有五种推荐词库：
纯四级、四级高频、纯六级、六级高频、四六级高频合并。

这些推荐词库排除了高中词汇和所记录的基础词形，因此词数会比常见的完整四六级词表少。
高频库还经过考试阅读样本筛选，属于精选补充词库，不等于全部考试词汇。
如果想从基础词开始学，或者有自己的学习范围，可以导入自己的词库；自定义导入不会自动剔除高中词。

最简单的导入办法：在 Excel 里准备“单词”和“释义”两列，复制后粘贴到导入窗口。
例如：
单词        释义
adapt       适应；调整
benefit     益处；使受益

也支持 CSV、TSV、TXT、JSON、XLSX 文件。只有单词、没有释义的文件，需要先补齐释义。
XLSX 读取第一张工作表；旧版 XLS 请先另存为 XLSX。
导入后先看预览，修正提示的错误，再确认导入并使用。

切换词库不会清空原词库的任务和进度，切回来可以接着学。
需要分享词库时，可以在词库管理里导出。

六、联想记忆怎么写？

学习时，或者完成今日任务后打开“逐词复习”，都可以点击“我的联想”写下自己的记忆方法。
写完点击“保存”；关闭窗口或点击“取消”不会保存这次修改。
逐词复习会显示你保存的联想，改完立即更新，下次打开也能看到；不会影响检测成绩或复习安排。
清空内容并保存，会恢复使用词库自带的联想。

如果希望让 AI 帮忙，可以这样设置：
1. 在自己的 DeepSeek 开放平台账号中准备 API Key（接口密钥）。
2. 点击首页的“AI 联想 · DeepSeek”，粘贴 Key。也可以从“菜单 → AI 联想设置”进入，模型先用默认选项即可。
3. 可以点击“测试连接”确认是否可用，再点击“保存”。
4. 回到“我的联想”，点击“AI 生成”。

生成风格偏向夸张、幽默、脑洞大，但要能把单词和词义联系起来，有清楚的逻辑和记忆点。
AI 联想限制在 80 字以内，没有最低字数要求；你自己手写的内容不受这个限制。

结果只是草稿：你可以修改、点击“换一种”，或用“撤回生成”恢复上一次生成前的内容。
只有点击“保存”才正式生效。生成失败或取消请求，不会覆盖原有内容。
AI 也可能联想得不合适，保存前请看一眼是否贴合词义。

AI 生成需要联网，费用由你自己的 DeepSeek API 账号承担；软件没有附赠共享 Key。
只有主动点击生成才发送当前单词、音标和释义，不发送旧联想、答案或整个词库。
“测试连接”只查询模型列表，不生成联想；取消生成不保证撤销服务端已经发生的费用。
Key 会在本机加密保存，不要发给别人。想移除它，在 AI 设置中清空 Key 并保存即可。
已经保存的联想可以离线查看，换电脑或 Windows 账号后需要重新填写 Key。

七、学习记录在哪？怎么备份？

如果程序旁有 portable.marker 文件，就是便携模式：
学习记录和导入的词库放在程序旁的 data 文件夹里。
这个 marker 文件用于选择存档位置，不要随意删除，否则程序可能改用另一个数据目录。

如果没有 portable.marker，且没有使用便携启动参数，默认数据目录是：
%LOCALAPPDATA%\WordMachineCommunity
可以按 Win + R，把上面这一行粘贴进去，打开该文件夹。

备份前先退出程序，再复制整个数据目录，不要只复制某一个 progress 文件。
数据目录里的 mistake-widget.json 只记录错题卡的隐藏和等待时间，请与学习存档一起保留。
更新软件前也建议先备份，保留自己的 data 和 portable.marker，不要用别人的存档覆盖它们。
只复制 EXE 到新位置，不会同时带走便携模式下的学习记录。

AI 密钥单独加密保存在下面的位置，便携模式也一样：
%LOCALAPPDATA%\WordMachineCommunity\ai\deepseek-settings.dat
不要把这个文件当作可以分享的配置，也不要把自己的数据目录发给别人。

八、遇到问题时

提示“保存失败”：先保留当前窗口，检查磁盘空间、文件夹权限或文件占用，再重试。
提示存档无法读取：先备份整个数据目录，不要急着删除存档或备份文件。
AI 连接失败：检查网络、Key 和账号余额；暂时不用 AI 也能继续手写联想和学习。
找不到旧进度：先检查是不是换了词库、移动了文件夹，或改变了 portable.marker。

提交问题时，说明操作步骤和错误提示即可；截图前遮住 Key，不要附上自己的完整学习存档。
