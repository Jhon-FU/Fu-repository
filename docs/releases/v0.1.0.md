首个公开运行包，面向 Windows x64。自带 .NET 运行时，下载、完整解压后即可使用。

## 下载哪个文件

- **WordMachineCommunity-win-x64.zip**：给普通使用者的运行包，解压后打开 `WordMachineCommunity.exe`。
- **SHA256SUMS.txt**：运行包的 SHA256 校验信息。
- GitHub 自动提供的 **Source code**：对应版本的源码，需要自行构建。

运行包还包含“用前读我.txt”、版本信息、撤销开机自启动的 CMD 和许可说明。不附带个人学习记录、API Key 或测试账号。

## 已包含的功能

- 五种推荐词库与自定义词库导入、预览、导出，按词库保留独立学习进度。
- 每日学习、复习和中文意思回忆检测，支持自评与个人联想。
- 可选 DeepSeek AI 联想，使用自己的 API Key，生成内容可以编辑后保存。
- 菜单一键开启开机自启动；同目录 CMD 可撤销。
- 错题悬浮卡限制在屏幕范围内；随机抽查通过可隐藏一小时，未通过需等待两分钟再试。
- 修复错题卡抢走输入焦点的问题，检测和隐藏答题时可以持续输入。

## 使用与更新

将程序解压到准备长期使用的文件夹，先阅读“用前读我.txt”。首次运行选择词库；自启动需要用户主动在菜单中开启。

学习数据默认保存在 `%LOCALAPPDATA%\WordMachineCommunity\`。更新前退出旧程序并备份自己的数据；本运行包不包含 `data/` 或 `portable.marker`，不会把任何预置账号作为你的学习记录。已经使用便携模式的用户请保留自己的数据目录及便携设置。

当前仅提供 Windows x64 运行包；检测仍采用中文意思回忆，可选拼写检测尚未加入。
