本次更新让 AI 联想更容易找到，并补全逐词复习的联想编辑功能。

## 更新内容

- 首页新增醒目的 **AI 联想 · DeepSeek** 按钮，一键打开 API 设置；菜单中的入口改名为“AI 联想设置”。
- **逐词复习**直接展示已保存的联想，新增“我的联想”按钮，与学习时使用同一个编辑窗口。
- 支持手动改写、AI 生成、换一种和撤回生成；点击保存后立即更新。清空并保存会恢复词库自带联想。
- 联想按词库保存，翻页、返回和重启后仍保留；修改不会影响检测成绩、历史答案或复习安排。
- 增加首页入口、复习编辑、保存失败重试、跨日保护、长文本布局和输入焦点的回归检查。

## 下载与更新

下载 **WordMachineCommunity-win-x64.zip**，完整解压后打开 `WordMachineCommunity.exe`。这是 Windows x64 自包含运行包，无需另行安装 .NET。GitHub 自动生成的 Source code 是源码包。

更新前退出旧程序并备份学习数据。默认数据目录为 `%LOCALAPPDATA%\WordMachineCommunity\`，可继续使用原有记录；便携模式请保留自己的 `data/` 和 `portable.marker`。如果移动了程序位置，请在菜单中更新开机自启动路径。

AI 功能需要使用者自己的 DeepSeek API Key；只有主动生成时才请求联想接口。此版本通过模拟 API 和隔离账号测试，不包含共享 Key、个人学习记录或测试账号。

运行包附带“用前读我.txt”、版本信息和“撤销开机自启动.cmd”，同时提供 `SHA256SUMS.txt` 校验文件。
