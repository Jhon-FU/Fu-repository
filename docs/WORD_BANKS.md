# 推荐词库的范围与来源

数据版本：2026.10.31。词库生成不读取个人学习进度；每个新用户得到相同的推荐词库。

## 分级和排除规则

1. 词头、中文释义、音标、四六级标签和已记录的屈折形式来自 ECDICT。只保留有中文释义且格式有效的英文词头。
2. 纯四级 = ECDICT 的 `cet4` 集合 − 高中/基础排除集合。
3. 纯六级 = ECDICT 的 `cet6` 集合 − `cet4` 集合 − 高中/基础排除集合。
4. 高中排除使用 2020、2025 两版高中课标词头、27 份高中教材/高考补充词表、ECDICT 的 `gk`/`zk` 标签及其已记录屈折形式。
5. 另保留 126 项人工核对的基础派生、拼写变体等排除判断；这些不是“官方课标直接收录”的声明。没有套用旧版机械拼接后缀生成的全部词形。

这是偏保守的增量筛选，可能排除部分有复习价值的基础词。分级以指定数据源为准，不能声称覆盖某一官方考试大纲的全部词汇。需要基础词或不同释义时，可导入自己的词库，不会再应用内置排除规则。

## 高频依据

四级、六级各收集 2015 年 6 月至 2026 年 6 月的 76 个公开试卷页面。各有 70 套可提取阅读原文，去重后各保留 279 个阅读模块。网站缺少阅读内容的页面和不足 80 个词形 token 的模块不计入；每页结果见 `data/sources/corpus-audit.json`。

- 四级统计只用四级阅读文章，六级统计只用六级阅读文章。
- 不统计听力、题干、选项、写作、翻译、答案、解析和网页导航。
- 对原文词形进行大小写统一；优先匹配独立词头，再按 ECDICT 中唯一对应的屈折形式归并。
- `according to` 不计作 `accord`；专名 `United States/Nations/Kingdom` 不计作动词 `unite`。
- 完全相同的规范化文章只计一次。不将多个同源数据集的次数相加。
- 高频阈值：**至少 3 个不同考期、跨至少 2 年、累计至少 5 次**。
- 按考期覆盖数、出现次数排序；合并高频库交替排列四级、六级词并去重。

因此，“高频”指当前阅读样本中的观察结果，不代表所有试卷、所有题型或未来出题概率。词典音标、释义可能含生僻义和历史行业用法，欢迎提供可复核的纠错。

## 重建与复核

```powershell
python scripts/build_wordbanks.py
python scripts/verify_wordbanks.py

# 若自行取得与 corpus-audit.json 对应的原始网页，可重新统计阅读原文。
# 两个目录都以 YYYY-MM-N.html 命名。命令只写本项目 data/sources。
python scripts/recount_reading.py --cet4-dir PATH_TO_CET4_HTML --cet6-dir PATH_TO_CET6_HTML
```

重建推荐词库只依赖仓库内紧凑来源快照。复核原始统计时不需要个人版程序、个人存档或旧项目路径。原始试卷文章不随仓库分发。
